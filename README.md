# Bomb Dodge

A simple Godot 4.x game project with a menu, solo/local play, bomb survival, and pickups.

## Run
1. Open the folder in Godot 4.x or 4.7.
2. Load `project.godot`.
3. Press Play.

## Controls
- Solo: WASD
- Local Multiplayer:
  - Player 1: WASD
  - Player 2: Arrow Keys

## Features
- Dark blue arena
- Seven selectable colors
- Bomb spawns and explosion logic
- Dash pickup for Red
- Shield pickup for Blue
- Survival timer and restart flow
