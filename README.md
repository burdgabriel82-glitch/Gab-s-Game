# Bomb Dodge

A simple Godot 4 project for a bomb-dodge survival game.

## How to run
1. Open the project folder in Godot 4.x.
2. Load `project.godot`.
3. Press Play.

## Controls
- Solo: WASD
- Local multiplayer: Player 1 uses WASD, Player 2 uses Arrow Keys

## Notes
- This project is intentionally simple and built with basic shapes and GDScript.
- The game includes a menu, color selection, bomb survival gameplay, and result screens.
