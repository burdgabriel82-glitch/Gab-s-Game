# Bomb Dodge

A simple Godot 4.x survival game project inspired by the Bomb Dodge brief.

## How to run
1. Open the folder in Godot 4.x.
2. Load `project.godot`.
3. Press Play.

## Controls
- Solo: WASD
- Local Multiplayer: Player 1 uses WASD, Player 2 uses Arrow Keys

## Features
- Dark blue arena
- Solo and local multiplayer modes
- Color selection with seven selectable colors
- Bomb spawning and explosion logic
- Red Dash and Blue Shield pickup abilities
- Survival timer and result screen
